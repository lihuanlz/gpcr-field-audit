\noindent This Supporting Information documents the complete computational
output of the accompanying repository (\texttt{gpcr-field-audit}): every analysis script,
the adjudication tables, the per-source meta-audit table, and the provenance of third-party
data. Numbers are transcribed verbatim from \texttt{results/}; scripts are plain Python~3
(numpy/scipy/matplotlib/pandas). The thirteen analysis scripts run in manuscript order under
\texttt{run\_all.py}, which archives each console output to \texttt{results/logs/} and writes a
manifest recording package versions, exit codes and file hashes; \texttt{PAPER\_MAP.md} maps every
script to the panel or table it backs.

\section{MOR extended-model residuals (code80)}

The Gillis arm-coordinate extended model is fitted to the MOR ligand
series; per-(nanobody, ligand, channel) residuals with standard
deviations, model-1 residuals and arm shifts are archived verbatim in
\texttt{mor\_code80\_residuals.csv} (67 rows). Example rows: Nb33 /
Morphine: $\log\tau$ residual $+0.031 \pm 0.102$, $\log R$ residual
$-0.021 \pm 0.092$; Nb33 / Oxycodone: $\log\tau$ $+0.192 \pm 0.146$.
